# Agent Platform

本仓库用于沉淀智能体平台（Agent Platform）的架构研究与演进过程。

内容分为两部分：

- `articles/`：按研究文章组织，每篇文章一个目录，每个核心讨论点一个独立小节文件。
- `architecture/agent-platform.md`：平台当前的核心架构文档，随每篇文章研究完成后增量演进。

## 写作原则

1. 中文优先：正文尽可能使用中文，重要英文术语仅在首次出现时补充原文。
2. 研究与结论分离：文章笔记保留来源观点与架构推导，架构主文档只保留已经形成的稳定结论。
3. 小节化沉淀：一次讨论聚焦一个核心问题，对应一个 Markdown 小节文件。
4. 保留演进历史：每篇文章独立提交，随后单独提交该文章带来的架构变化。
5. 工程标识保持英文：目录名、文件名、接口名、事件名和代码标识符使用稳定英文命名。

## 提交约定

每篇文章采用两阶段提交：

```text
文章研究提交
  ↓
架构吸收 / 修正
  ↓
架构演进提交
```

这样可以通过 `git log -- architecture/agent-platform.md` 直接回溯平台架构如何随着研究逐步形成。
