# 从人工审批走向可监督执行

## 文章中的关键观点

Anthropic 的总体建议不是要求所有智能体采用固定的人机交互模式，而是关注：人是否处于能够有效观察、干预和重新引导智能体的位置。

文章认为，要求人类批准每一个动作会制造大量摩擦，却未必带来对应的安全收益。更有经验的 Claude Code 用户表现出的模式是：减少逐步审批，同时保持主动监控，在需要时打断和纠偏。

Anthropic 也提醒，软件工程是一个相对容易建立这种监督方式的领域：代码可以测试、差异可以审查、修改可以回滚。在法律、医疗、金融等领域，验证智能体输出本身可能就需要很高的专业成本，因此同样的自主与监督模式未必适用。

## 我们的架构分析

高自主智能体的产品界面不应只围绕“是否批准这个动作”，而应帮助人保持对整个执行过程的态势感知。

人工可见视图至少应该持续回答：

```text
现在在做什么？
为什么做这一步？
处于哪个阶段？
下一步准备做什么？
当前风险边界是什么？
我现在可以怎样介入？
```

这意味着需要把内部执行事实投影成面向人的监督视图：

```text
运行时事件 + 智能体追踪 + 工作状态 + 风险状态
                     ↓
                监督投影
                     ↓
                    人
```

它和面向模型的观察投影是两个不同方向：

- 观察投影优化模型所需的相关性、上下文效率和可操作性；
- 监督投影优化人的可理解性、进度感知、风险可见性和介入准备度。

## 对 Agent Platform 的影响

可以把人工监督面作为治理与运行时之间的横切能力：

```text
人工监督面
├── 进度投影
├── 风险可见性
├── 动作 / 计划可见性
├── 暂停 / 恢复
├── 中断
├── 纠偏 / 实时引导
├── 审批
├── 评审
├── 验收
└── 升级
```

它与人类治理面不同：治理面负责目标、风险边界、预算和最终验收；监督面负责运行过程中如何观察、介入和纠偏。

同时，安全自主性的上限高度依赖验证成本、可逆性、可观测性和隔离强度：

```text
验证成本越低
可逆性越强
可观测性越好
隔离边界越可靠
      ↓
可安全授予的自主空间越大
```

## 核心结论

> **生产级智能体的目标不是最大化自主性，而是在可验证、可观察、可干预的边界内，最大化有用的自主性。**

> **有效监督的判断标准不是“有没有审批框”，而是人是否真的能够理解执行状态，并在需要时及时改变执行轨迹。**
