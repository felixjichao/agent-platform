# Building effective agents

- 原文：<https://www.anthropic.com/engineering/building-effective-agents>
- 研究主题：从工作流与智能体的区别出发，抽象统一执行内核需要支持的控制方式。

## 为什么研究这篇文章

这篇文章提供了一个非常好的起点：不要先从框架、角色或多智能体数量出发，而是先看任务执行过程中**谁拥有执行控制权**。这使我们可以把对话、科研助手、确定性工作流、自主智能体、企业知识库等产品形态放到同一个执行模型中讨论。

## 对平台架构的核心影响

- 产品形态与执行范式必须解耦。
- 工作流和智能体不是两个完全独立的平台，而是执行控制权不同的连续谱。
- 统一运行时不应该固化某一种工作流图或 Agent Loop，而应提供更基础的执行、状态与控制原语。
- 多智能体首先是更高层的编排拓扑，不应成为运行时最底层抽象。
